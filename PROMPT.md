# Промпт: лендинг магазина комиксов «Реликварий»

**Инструмент:** Claude Code (Anthropic). Чистые HTML + CSS + JS, без фреймворков и сборки, деплой на GitHub Pages.

---

## Мастер-промпт (основной)

> Сделай одностраничный лендинг «Реликварий мрачных комиксов» — магазин готических комиксов. Эстетика — готическая инди-игра: доспехи, мечи, шлемы, венки с шипами, колокола, свечи, кладбища. Палитра строго ч/б/серая и очень мрачная: почти чёрный `#090808`, костяной `#e9e5da`, серые; красный `#a3121a` — только точечно (цены, печать, полоска). Зерно плёнки и виньетка поверх всего.
>
> **Эталон — henry.codes.** Повтори его дизайн-язык, но не копируй контент:
> - hero: гигантское слово «РЕЛИКВАРИЙ» сверхсжатым жирным гротеском на всю ширину, на него наезжает курсивное «мрачных» с обводкой цветом фона, ниже «КОМИКСОВ» тонкой антиквой капсом;
> - справа — пиксельная гравюра в рамке 2px со скруглением, рядом вертикальная подпись «(Листайте осторожно. Здесь колется.)»;
> - под заголовком бегущая строка между двумя линиями 2px, затем список «Залы»: название + бледное размытое описание, которое проявляется при наведении;
> - полоска-объявление сверху с «переливающейся» линией, нумерация «(01)», гигантский заголовок секции «КАТАЛОГ» на всю ширину, сетка-оверлей с `mix-blend-mode: difference`.
>
> **Шрифты** (все с кириллицей): Alumni Sans 900 (вместо Manuka), Cormorant 300 + italic (вместо Louize Display), Onest (вместо Neue Montreal).
>
> **Сценарий:** пользователь просто листает вниз и смотрит список комиксов. Никаких форм и корзин.

## Промпт 2 — пиксельные обложки
> Обложки должны быть пиксельными, как гравюра с горгульей на henry.codes: 1-битный дизеринг, только два цвета. Рисуй сцену на маленьком canvas (120×170) в оттенках серого: луна с ореолом, туман, тёмный силуэт эмблемы (шлем, меч, венец, щит, колокол, свеча, башня, кубок, череп, скрещённые мечи), снизу кладбище с крестами. Затем подними контраст (levels) и прогони Floyd–Steinberg в два цвета. Увеличь через `image-rendering: pixelated`. Часть обложек светлые, часть тёмные. При наведении картинка «мерцает»: каждые 110 мс заново дизерится с новым шумом. Для hero — крылатый рыцарский шлем с терновым венцом и мечом.

## Промпт 3 — карточки каталога и атрибутика
> Каждая карточка — строка на всю ширину: номер (01), жанр капсом, гигантское название, описание курсивом, автор и цена красным, обложка в рамке с подписью «№ I · Реликварий» и красной печатью ✠ у некоторых. Обложки чередуются слева и справа. На фоне каждой карточки — тонкие контурные атрибуты (корона, готическое окно, цепь, крест, венец, скрещённые мечи) и огромная римская цифра контуром. При наведении карточка подсвечивается, атрибут поворачивается и проявляется, название сдвигается, обложка приподнимается с красной тенью, остальные строки размываются. Проверь в браузере на 1280 и 375 px: нет горизонтального скролла, заголовки не вылезают за экран.
